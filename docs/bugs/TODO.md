## [B1] 主页顶部卡片：右侧头像/动画遮挡左侧「在一起 X 天」文字

- **状态**：待修复（2026-08-16 用户反馈，APK v1.1 已装，下次发版一起改）
- **现象**：主页顶部渐变卡片里，右侧头像（双人时含丘比特射爱心动画）位置偏高，**挡住了上方/左侧「在一起 X 天」文字**
- **截图**：`docs/bugs/home_avatar_overlap.jpg`（用户 QQ 截图，真实设备效果）
- **用户期望**：头像（及动画区）**往下放一点**，不与文字重叠
- **代码位置**：`app/lib/pages/home_tab_page.dart`
  - 顶部卡片 Row：`~107-218` 行
  - 右侧头像+动画组：`~188-218` 行（`Avatar` radius 26 ×2 + `_LoveAnimator` 46×52）
  - `_LoveAnimator`：爱心从丘比特射出（向左 3 秒 / 向右 3 秒），爱心 Positioned 可能溢出 Stack（`clipBehavior` 默认裁剪？需确认），向左射出时覆盖左侧文字区
- **疑似原因**（待验证）：
  1. 右侧 `Row`（头像+动画）与左侧 `Expanded` 文字在垂直方向 `CrossAxisAlignment.center`，小屏/文字换行时视觉重叠
  2. `_LoveAnimator` 向左射出的爱心溢出覆盖文字
  3. 双人布局右侧总宽约 158px，窄屏挤压左侧文字宽度导致换行
- **修复方向**（下次发版选一）：
  - 右侧头像组加 `Padding(top: …)` 或整体下移
  - 左侧文字区与右侧区之间加间距/左侧文字 `Expanded` 保障最小宽度
  - 丘比特爱心动画改为**仅向右飞**或裁剪溢出（`clipBehavior: Clip.hardEdge`）
  - 或卡片改 `Column` 布局（文字在上、头像在下）
- **验证**：真机截图对比（同机型同文字内容）；语义/像素检查无重叠
